      How it works

      1. Plan. An AI model reads your question and picks up to five checks from a menu of paid data APIs.
      2. Pay. You see the exact price before anything is bought. A checkout agent creates the PayPal order through PayPal Agent Toolkit, and you pay once.
      3. Buy. The agent pays the data provider per call in USDC (x402 on Base) and collects the results.
      4. Refund. Checks that return nothing are refunded to your PayPal on the spot; the checkout agent issues the refund through PayPal Agent Toolkit.
      5. Answer. The model writes a short answer that cites the check behind every fact.
      PayPal sandbox demo. Data checks are bought live from a public pay-per-call API.
